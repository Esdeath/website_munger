# 芒格关键词深度长文

从查理·芒格的 83 篇致股东信、演讲与访谈（约 124 万字）中，提取出他反复强调的关键词，每个关键词单独成文。每篇都以**第三人称解读体**写作，大量引用原文并标注出处——编者的话是正文，芒格的话是引文，泾渭分明。

全部引用均逐字摘自语料库，经脚本逐字核验，杜绝杜撰。三十一篇合计 **622 处引用**。

## 投资原则

### [能力圈：知道自己不知道什么](能力圈-知道自己不知道什么.md)
> 「如果你确有能力，你就会非常清楚你能力圈的边界在哪里。没有边界的能力根本不能称之为能力。」

知道边界，比拥有能力更重要。（16 处引用）

### [护城河：宽且不断变宽的护城河](护城河-宽且不断变宽的护城河.md)
> 「旧的护城河正在被填平，而新的护城河比以前更难预测，所以事情变得越来越难。」

最深的护城河，是每天都在变宽的那条。（18 处引用）

### [长期持有：坐等伟大公司复利增长](长期持有-坐等伟大公司复利增长.md)
> 「对于个人而言，做到长期持有几家伟大公司的股票而什么都不用做的地步，有许多巨大的优势：你付给交易员的费用更少，听到的废话也更少，如果这种方法生效，税务系统每年会给你1-3%的额外回报。」

最难的不是买入，而是买对之后坐着不动。（22 处引用）

### [耐心·等待·好球区：只挥好球](耐心等待好球区-只挥好球.md)
> 「我的搭档沃伦·巴菲特讲过，手握大量资产，可以自由配置，就像手握棒球棒，等待好球扔过来，愿意等多久都可以，你不挥棒击打，也没人罚你出局。」

投资不是每一球都要挥棒，而是等到胜率和赔率都站到你这边。（17 处引用）

### [复利：让时间替你工作](复利-让时间替你工作.md)
> 「对于个人而言，做到长期持有几家伟大公司的股票而什么都不用做的地步，有许多巨大的优势：你付给交易员的费用更少，听到的废话也更少，如果这种方法生效，税务系统每年会给你1-3%的额外回报。」

复利不是一张曲线，而是一套让现金、时间和低摩擦持续工作的系统。（32 处引用）

### [内在价值：价格背后的真实重量](内在价值-价格背后的真实重量.md)
> 「所有优秀的投资本质上，都是以较低的价格获得更高的价值。」

价格每天叫喊，内在价值才是一个生意真正的经济重量。（32 处引用）

### [机会成本：用最好的选项做标尺](机会成本-用最好的选项做标尺.md)
> 「生活本身就是一系列机会成本的选择。有智慧的人善于比较机会成本。从机会成本的角度考虑，很多问题会迎刃而解。」

每一个决定，都该拿你能找到的最好选项去丈量。（22 处引用）

## 写作方法

每篇文章遵循统一的八节骨架：题记 → 钩子 → 他怎么定义 → 跨年代的回响 → **反过来想** → **跨学科透镜** → 落到实处 → 边界与误读 → 给今天的你 → 出处索引。其中"反过来想"与"跨学科透镜"两节为芒格思维的两根支柱，每篇必有。
