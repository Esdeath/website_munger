# 简单的避免痛苦的心理否认：不承认事实，痛苦不会消失

人不只会逃避外部危险，也会逃避让自己难受的事实。

体检指标异常，却说“应该没事”；关系已经破裂，却说“只是最近压力大”；投资逻辑失效，却说“市场迟早会懂”；项目没有前景，却说“再坚持一下就会反转”。

这就是简单的避免痛苦的心理否认：为了减少当下的精神痛苦，人会否认、淡化或推迟面对已经出现的坏消息。

## 一、否认为什么有效

否认在短期内确实有效。

它能让人暂时不焦虑、不羞愧、不恐惧，也不用马上行动。问题在于，事实不会因为被否认就停止发展。

```text
病情不会因为不检查而好转；
现金流不会因为不看报表而改善；
关系不会因为不谈问题而恢复；
风险不会因为不写进计划而消失。
```

否认保护的是情绪，不是现实。

## 二、它最容易出现在高痛苦场景

越是承认事实会带来巨大心理成本，人越容易否认。

第一，身份受威胁。

如果承认错误意味着“我不是一个聪明投资者”“我不是一个好伴侣”“我不是一个成功创业者”，人就更愿意拒绝事实。

第二，损失已经很大。

损失越大，承认越痛。于是沉没成本谬误和心理否认会互相强化。

第三，短期行动代价很高。

面对坏消息之后，可能要止损、道歉、换方向、裁撤项目或重建生活。否认让人暂时逃过这些动作。

## 三、如何识别自己在否认

可以留意几句话：

```text
先别想这个。
再等等看。
这只是暂时的。
大家都这样。
只要不说破，就还有机会。
```

这些话不一定错，但如果它们反复出现，而且每次都阻止你查看证据、做小行动或设定截止点，就可能是心理否认。

真正的判断会问：

```text
如果这是别人的事，我会怎么看？
如果坏趋势继续三个月，会发生什么？
哪些事实会让我承认问题已经存在？
我现在能做的最小修正是什么？
```

## 四、纠偏方法

第一，降低面对事实的疼痛。

不要把承认问题等同于承认人生失败。事实只是反馈，不是审判。

第二，设置定期体检。

财务、健康、关系、项目都需要外部指标。定期看指标，可以避免只在危机时面对现实。

第三，把问题拆小。

如果一次性面对全部真相太痛苦，就先处理一个可行动的小事实。

第四，引入可信旁观者。

当自己不敢看时，让一个不被同样情绪绑架的人帮你看。

## 五、边界

不是所有暂时不处理都是否认。

人在重大打击后需要缓冲，心理系统需要时间恢复。问题不在于短暂停顿，而在于长期用“我还没准备好”替代所有行动。

真正健康的缓冲，会通向面对；有害的否认，会通向拖延和恶化。

## 六、和其他模型的关系

简单的避免痛苦的心理否认和损失厌恶相连。人不愿确认损失，于是拒绝事实。

它和沉没成本谬误相连。过去投入越多，越不愿承认方向错误。

它和避免怀疑倾向相连。人为了尽快摆脱不确定痛苦，会抓住一个安慰性结论。

它也和认知谦逊相连。承认自己会逃避事实，是看见事实的第一步。

## 一句话总结

简单的避免痛苦的心理否认提醒我们：

```text
不看事实，只能减少一时疼痛；
面对事实，才可能减少长期代价。
```

逃避坏消息，常常是在让坏消息获得更多时间。
