# 第一性原理思维：拆到不能再拆，再重新推理

`回归第一性原理` 不是回到一句口号，而是回到当前问题中不能继续由惯例替代的事实、约束和可验证关系，再从这些基础重新推导方案。

很多问题看起来很难，并不是因为它真的无解，而是因为我们一开始就站在了别人的答案上。

“这个行业就是这样。”

“过去都是这么做的。”

“成本本来就这么高。”

“用户不会接受。”

“好公司就应该按这个指标估值。”

这些话听起来像事实，其实很多只是历史惯例、行业共识、旧经验、供应链结构、组织惰性或者别人没想清楚的中间结论。第一性原理思维要做的，就是把这些东西一层层剥掉，回到最基本、最不可再拆的事实，然后从那里重新推理。

它不是让你“从零开始乱想”，而是让你区分：

```text
什么是真正的基本事实？
什么只是从事实推导出来的经验规则？
什么只是大家重复太久的假设？
```

## 一、第一性原理不是一句创新口号

第一性原理的核心，是回到一个问题在当前情境下不可继续简化的要素。

如果你在做工程问题，基本要素可能是材料、能量、力学约束、制造工艺。  
如果你在做商业问题，基本要素可能是客户需求、成本结构、现金流、竞争约束。  
如果你在做投资问题，基本要素可能是未来自由现金流、资本需求、确定性、价格和风险。  
如果你在做个人决策，基本要素可能是时间、精力、健康、关系、长期目标和不可逆后果。

第一性原理不是寻找宇宙的终极真理。多数时候，它只是要求你在一个具体问题里找到不能再往下拆的事实和约束。

它和普通经验推理最大的区别是：经验推理从“别人怎么做”出发，第一性原理从“这件事到底由什么构成”出发。

## 二、人为什么默认不用第一性原理

因为类比推理太省力。

面对一个新问题，大脑会自动寻找相似场景：这件事像过去哪件事？别人怎么做？行业怎么做？成功案例怎么做？然后我们在已有方案上做一点微调。

这在日常生活里很有用。你不需要每次做饭都重新研究热力学，也不需要每次开车都从牛顿力学推导刹车距离。经验节省认知成本。

但类比推理有一个致命限制：它只能在过去方案附近搜索。

如果过去方案本身建立在错误假设上，你只会把错误做得更精细。  
如果行业共识只是历史路径依赖，你只会沿着旧路径继续走。  
如果最优解不在已有方案附近，类比推理很难看见它。

所以，第一性原理不是日常默认模式，而是关键问题上的主动切换。

当你遇到高成本、强惯例、高不确定、所有人都说“不可能”的问题时，就要小心：你可能不是撞上了事实边界，而是撞上了旧假设边界。

## 三、马斯克火箭案例真正说明了什么

火箭贵，这是航天行业长期默认的事实。

但“贵”本身不是第一性原理。它可能来自材料成本，也可能来自供应链层层加价、低产量、采购制度、外包结构、技术封闭、风险溢价和历史惯例。

第一性原理思维会把问题拆开：

```text
一枚火箭由什么材料构成？
这些材料在市场上的真实价格是多少？
制造、测试、组装、发射中哪些成本是真实约束？
哪些成本只是行业结构带来的加价？
哪些环节可以重新设计？
```

当你发现原材料成本只占最终售价很小一部分时，“火箭必然这么贵”这个判断就开始松动。它不再是物理约束，而变成了工程、组织和供应链问题。

这才是这个案例的重点。

第一性原理不是魔法。它不能把火箭制造变简单，也不能绕过工程难题。它只是先把“不可改变的事实”和“被误认为事实的惯例”分开。分开之后，新的路径才可能出现。

## 四、芒格式第一性原理：穿透规则，回到价值本质

第一性原理不只属于工程。

在投资里，它表现为回到企业价值的本质。

喜诗糖果的案例很典型。按早期价值投资的传统框架，便宜资产很重要，账面资产低估是核心线索。可是如果你回到更基本的问题：一家企业的价值到底由什么决定？答案就不是“账面资产有多少”，而是它未来能产生多少现金流、这些现金流有多确定、需要多少新增资本才能维持或增长。

从这个角度看，喜诗糖果的关键不是厂房和设备，而是品牌、客户心理、提价能力、低资本投入和稳定现金流。旧框架会觉得它“贵”，第一性原理会追问：贵是相对于什么？相对于账面资产贵，还是相对于未来现金流便宜？

这就是芒格式的第一性原理：不是背叛前人的智慧，而是穿透前人的规则，回到规则背后的基本事实。

保险业务也是一样。

行业惯例可能追求保费规模，但保险的本质不是规模，而是风险定价。保费在赔付前形成浮存金，浮存金可以投资，但前提是承保纪律不能被破坏。如果为了规模放松定价，拿到的保费可能只是未来亏损的诱饵。

从第一性原理看，保险公司的核心不是“收了多少保费”，而是“是否以合理价格承担了可理解的风险”。

## 五、第一性原理的三步

第一步，列出当前假设。

把你脑子里的“当然如此”写下来。成本为什么高？用户为什么不会买？行业为什么必须这样？项目为什么做不成？投资为什么值得？很多假设一写出来，就会暴露它只是继承来的观点。

第二步，拆到基本事实。

问：哪些东西是确定存在的？哪些约束不可违反？哪些数据可以验证？哪些规律在当前情境下必须成立？哪些只是别人过去的做法？

第三步，从基本事实重新组合。

不要急着回到旧方案。问：如果只保留这些基本事实，我还能设计出哪些方案？哪些变量可以替换？哪些环节可以取消？哪些成本不是必要成本？哪些目标可以用完全不同的方式实现？

这个过程常常会慢下来，但它的慢，是为了避免在错误假设上跑得更快。

## 六、两种实用工具：苏格拉底式提问和五个为什么

第一性原理听起来抽象，但它可以通过具体提问落地。

苏格拉底式提问适合拆观点：

- 我为什么会这么想？
- 这个想法从哪里来？
- 我怎么知道它是真的？
- 如果相反观点成立，会怎样？
- 支持它的证据是什么？
- 有没有其他解释？
- 如果我错了，后果是什么？
- 我最初提出的问题本身是否问错了？

它的作用，是把“我觉得”拆成可检查的事实、假设和推理链。

五个为什么适合拆原因。

你不断追问“为什么”，直到答案落到可验证的事实或不可再拆的约束上。如果最后得到的是“因为一直以来都是这样”“因为大家都这么说”“因为领导以前这么定”，你找到的不是第一性原理，而是惯例或权威。

真正有用的追问不是为了显得聪明，而是为了找到哪一层才是问题真正发生的地方。

## 七、第一性原理能推翻错误教条

胃溃疡的医学史提供了一个好例子。

很长时间里，人们认为胃里强酸环境不适合细菌生存，所以胃溃疡主要被解释为压力、生活方式或胃酸问题。这个判断看起来像医学事实，实际上是一条未经充分检验的教条。

当研究者发现幽门螺杆菌与胃溃疡有关时，他们做的事情就是把“胃是无菌的”从第一性原理的位置上拿下来，重新检验事实。后来，抗生素治疗改变了大量患者的命运。

这里的重点不是医学细节，而是思维结构：一旦你把假设误认为基本事实，整个领域都会在错误地基上继续建楼。

第一性原理的价值，就是允许你问一句很不合群的话：

```text
我们确定这是事实吗，还是只是一个被重复太久的假设？
```

## 八、第一性原理不是抛弃前人知识

很多人误用第一性原理，把它理解成“我不管别人怎么想，我自己从零开始想”。

这很危险。

真正的第一性原理需要知识基础。你要知道哪些是基本事实，哪些是经验规则，哪些是领域内已经被反复证伪的错误路径。知识越浅，越容易把自己的直觉误认为第一性原理。

马斯克能拆火箭成本，不是因为他无视火箭科学，而是因为他愿意学习材料、发动机、制造和供应链。芒格能穿透投资规则，不是因为他无视格雷厄姆，而是因为他理解了格雷厄姆方法背后的价值逻辑。

第一性原理不是反知识，而是要求你把知识拆开：事实归事实，假设归假设，经验规则归经验规则。

## 九、什么时候不该用它

第一性原理很强，但不该滥用。

第一，日常小事不值得每次重推。  
认知资源有限。买牙刷、选午餐、安排普通会议，不需要从材料科学和组织理论重新推导。

第二，时间敏感的场景不适合深挖太久。  
有些时候，足够好的经验规则比完美推理更有用。急救、交易执行、现场故障处理，都需要预先训练过的模式识别。

第三，不在能力圈内时要谨慎。  
如果你连基本事实都识别不出来，就很容易把错误假设当成底层原理。第一性原理不是能力圈的替代品。

第四，推理正确不等于执行可行。  
火箭原材料便宜，不代表造火箭容易。企业理论上能降本，不代表组织能做到。第一性原理能打开可能性，但不能省掉工程、管理、资本和执行。

## 十、在投资和商业里怎么用

遇到行业共识，问：

```text
这是自然规律、经济规律，还是历史惯例？
```

遇到高成本，问：

```text
成本由哪些部分构成？哪些是真成本，哪些是结构性加价？
```

遇到估值指标，问：

```text
这个指标为什么能代表价值？它在什么条件下会失效？
```

遇到管理规则，问：

```text
这条规则服务于什么目标？如果去掉它，真实风险会增加吗？
```

遇到产品方案，问：

```text
用户真正要完成什么任务？现有方案有哪些只是历史包袱？
```

遇到个人计划，问：

```text
我真正想获得的结果是什么？现在的方法是必要路径，还是别人走过的路径？
```

第一性原理最适合用在两个场景：一是你怀疑共识错了；二是你需要突破旧解法。

## 十一、和其他模型的关系

第一性原理和奥卡姆剃刀相互配合。第一性原理负责把问题拆到底层事实，奥卡姆剃刀负责删掉不必要的假设。

它和逆向思维也很适合一起用。第一性原理告诉你什么是真的，逆向思维提醒你哪些条件一旦失败就会毁掉结果。

它和地图不是疆域关系密切。行业框架、估值模型、成功案例都是地图；第一性原理会逼你回到疆域本身，检查地图遗漏了什么。

它和能力圈不可分。只有在足够理解一个领域时，你才知道什么是真正底层，什么只是中间层规则。

它也能对抗铁锤人倾向。铁锤人会把熟悉的方法套到所有问题上，第一性原理会问：这个问题本身到底需要什么？

## 十二、一句话总结

第一性原理思维不是把所有东西推倒重来，而是把事实、假设、惯例和推论分开。

它的真正力量，是在所有人都被“向来如此”困住时，回到最基本的事实，重新问：

```text
如果只从这些事实出发，我们还能怎样做？
```

能问出这个问题，你就已经走出了旧答案的影子。
