# 正式文章

这个目录保存已经写成完整文章的思维模型。

写作规则：

- 正文讲模型本身，不在正文中反复说“某书第几章”。
- 来源书籍和章节统一放在文末 `## 来源说明`。
- 文章要有主线，不写成资料卡片。
- 合并文章优先参考 [概率思维与期望值](概率思维与期望值.md)：开头列明合并词，正文分别吸收别名、子模型、案例与边界，来源说明解释归并理由。
- 单一模型可参考 [五力模型](five-forces.md) 的写法。
- [护城河](护城河.md) 展示多来源、长别名和章节式条目的组织方式。
- 正式文章清单以 `../data/article_registry.json` 为准，当前共 178 篇。
