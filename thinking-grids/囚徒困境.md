# 囚徒困境：每个人都理性，为什么结果一起变差

有些行业的问题，不是管理层不努力，也不是需求不增长，而是竞争结构让所有人都陷入坏结果。

每家公司单独看都在做理性选择：降价抢客户、扩张产能、增加补贴、提高投放。但所有人都这样做，最后价格下跌、利润消失、行业一起受伤。

这就是 `囚徒困境`：个体最优策略，可能导致集体次优结果。

## 一、经典结构：背叛是个人理性，合作是集体最优

经典囚徒困境里，两名嫌疑人分别被审讯。

如果两人都沉默，各判轻刑。如果一人背叛、一人沉默，背叛者获益，沉默者受重罚。如果两人都背叛，双方都得到较差结果。

站在每个囚徒的角度，无论对方怎么选，背叛都更安全。于是两人都背叛。

问题在于：两人都背叛的结果，明显差于两人都合作。

这就是囚徒困境最重要的洞见：

```text
纳什均衡不等于最优结果。
个体理性可能制造集体非理性。
```

## 二、价格竞争与囚徒困境

商业中最常见的囚徒困境，是价格战。

如果所有企业都维持价格纪律，行业利润可以不错。但任何一家都可以通过降价抢份额。对单个企业来说，率先降价有诱惑；对被攻击的企业来说，跟进降价又是防守。

结果是所有人都降价，市场份额变化不大，利润却一起下降。

这就是 `价格竞争与囚徒困境` 的核心。它最容易发生在这些行业：

- 产品高度同质化；
- 客户价格敏感；
- 产能过剩；
- 固定成本高、边际成本低；
- 价格透明，竞争者能快速跟进；
- 参与者缺乏长期信任或约束机制。

航空业就是典型。空座位无法库存，多卖一个座位的边际成本很低，于是每家公司都有动力降价填座。所有公司都这样做，行业长期利润很薄。

## 三、软饮料制造商的囚徒困境

`软饮料制造商的囚徒困境` 和 `可口可乐与百事可乐的囚徒困境` 更细地说明：哪怕是强品牌寡头，也会面对合作与背叛的张力。

可口可乐和百事可乐长期竞争。它们可以通过降价抢份额，也可以把竞争集中在品牌、渠道、广告和新品上。

如果双方陷入全面价格战，消费者短期受益，但两家公司利润都会受损。更理性的做法，是避免把竞争简化为价格互砍，而是在品牌心智、分销能力和产品组合上竞争。

这不是说企业可以公开串通。反垄断法禁止显性价格联盟。这里的重点是：在重复博弈的寡头市场里，企业会逐渐理解，过度价格战会破坏整个行业的利润池。

换句话说，寡头结构有时能减轻囚徒困境；完全分散、产品同质、参与者很多的市场，则更容易陷入价格战。

## 四、重复博弈：合作如何变得可能

一次性囚徒困境中，背叛很有诱惑力。

但现实商业通常不是一次性博弈。供应商、客户、竞争者、管理层、股东会反复互动。重复博弈会改变收益结构。

如果你今天背叛，未来会失去信誉、合作机会和长期收益。于是，合作不再只是道德选择，也变成理性选择。

阿克塞尔罗德研究重复囚徒困境时发现，“以牙还牙”这类策略很稳健：先合作，对背叛做出回应，但不无限报复，一旦对方恢复合作就恢复合作。

这给商业关系一个实用原则：

```text
初始善意，但不要软弱；
及时回应背叛，但不要陷入永久报复；
让自己的策略清楚可预期。
```

## 五、怎样打破囚徒困境

打破囚徒困境，不能只靠劝人善良。要改变结构。

第一，减少参与者数量。参与者越少，行为越容易被观察，长期关系越容易形成。

第二，增加互动次数。一次性交易更容易背叛，长期合作更容易建立信誉。

第三，提高背叛成本。合同、保证金、声誉系统、监管处罚，都是让背叛变贵。

第四，增加差异化。品牌、专利、网络效应、转换成本可以让企业脱离同质化价格战。

第五，让策略透明。清楚告诉对方什么行为会被视为背叛，什么行为会带来合作，有助于减少误判。

## 六、投资中的行业结构诊断

投资者分析一个行业时，要先看它是否天然处在囚徒困境里。

如果一个行业需求增长很快，但所有玩家都要不断降价、补贴、扩产才能维持份额，那么需求增长未必会变成股东回报。

真正值得警惕的是“看起来繁荣、实际上互相伤害”的行业。收入增长掩盖了利润池被竞争吞噬。

一个好行业往往具备相反特征：参与者少，产品有差异，客户不只按价格选择，产能扩张克制，长期关系和信誉重要。

## 关联模型

- `激励机制`：囚徒困境来自个体激励和集体利益错位。
- `垄断与寡头`：寡头结构有时更容易维持合作均衡。
- `护城河`：差异化和转换成本能让企业摆脱同质化价格战。
- `竞争性毁灭`：价格战是竞争性毁灭的常见表现。
- `公地悲剧`：公共资源场景中的囚徒困境。
- `信息不对称`：不知道对方策略和成本，会改变博弈结果。
