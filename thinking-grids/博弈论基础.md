# 博弈论基础：你的选择会改变别人的选择

有些决策，不能只问自己应该怎么做。

你降价，竞争对手会不会跟着降？你公开承诺长期投入，对手会不会退出？你对合作伙伴让利一次，对方会不会把它当成长期惯例？你在谈判中表现得太急，对方会不会提高要价？

这类问题和天气、骰子、自然风险不一样。

天气不会因为你带伞就故意下雨，骰子不会因为你下注就改变点数。但人会反应。公司会反应。竞争对手、客户、供应商、员工、监管者都会反应。

博弈论要处理的，就是这种互动决策：

```text
我的最优选择，取决于别人怎么选；
别人的最优选择，也取决于他们认为我会怎么选。
```

这句话一旦进入你的大脑，很多商业和人生问题就会变形。

你不再只看“我想要什么”，还要看“别人在这个结构里被激励去做什么”。你不再只问“这个策略好不好”，还要问“这个策略会引发什么反应”。你不再只努力把一局棋下好，还会开始问：我为什么要坐在这张棋盘前？

## 一、博弈论研究的不是聪明人，而是互动结构

博弈论研究的是多个参与者之间的策略互动。

一个最简单的博弈，至少包含三样东西：

- 玩家：谁参与了这个局面。
- 策略：每个玩家可以选择什么行动。
- 收益：不同策略组合下，每个玩家得到什么、失去什么。

很多人分析竞争时，第一个错误就是把玩家认错。

他们以为自己只是在和直接竞争对手博弈，却忽略了客户也在选择、供应商也在选择、平台也在选择、监管者也在选择、潜在进入者也在观察。

比如一家餐饮店决定降价。它面对的不只是附近另一家餐厅。顾客会改变对价格的预期，外卖平台会调整推荐和补贴，员工会承受更高出餐压力，供应商可能被要求压价，同行可能跟进，房东也可能看到生意变好后提高租金。

所以，博弈论第一步不是计算，而是画出局面：

```text
谁在局里？
他们各自想要什么？
他们能做什么？
他们会如何回应我？
```

只看自己的行动，是单人决策。看见其他人的反应，才进入博弈论。

## 二、纳什均衡：稳定不等于好

博弈论里最重要的概念之一，是纳什均衡。

它的意思是：在给定其他人策略的情况下，每个人都选择了自己的最优策略，因此没有人愿意单方面改变行动。

注意，这里说的是“稳定”，不是“最好”。

这点特别重要。

一个行业所有公司都卷入价格战，利润薄得可怜，但谁也不敢先涨价。因为只要自己涨价，客户就可能流向对手。这个状态可能是稳定的，但不是好的。

两家公司都过度投放广告，谁都知道广告费用吃掉了利润，但谁也不敢停。因为一停，市场声量可能被对手拿走。这个状态也可能是稳定的，但对双方都不好。

团队里所有人都加班到很晚。每个人都知道效率并没有变高，但谁也不敢第一个正常下班。这个状态仍然可能是稳定的，却是糟糕的。

这就是纳什均衡给人的第一记耳光：

```text
一个局面能长期存在，不代表它合理；
一个结果稳定，不代表它优秀。
```

很多坏结构之所以难改，不是因为没人知道更好的结果，而是因为没有人能靠单方面改变把大家带到更好的结果。

## 三、囚徒困境：个体理性如何造成集体愚蠢

囚徒困境是博弈论最著名的例子。

两个嫌疑人被分开审讯，无法沟通。每个人都有两个选择：合作沉默，或者背叛认罪。

如果两人都沉默，处罚较轻。  
如果两人都认罪，处罚较重。  
如果一个认罪、一个沉默，认罪者获益，沉默者吃大亏。

站在单个人角度看，无论对方怎么选，自己认罪似乎都更划算。于是两个人都认罪，结果比双方都沉默更差。

这个模型真正想说的不是“人很坏”，而是：

```text
在某些激励结构下，每个人都做对自己有利的事，集体却得到坏结果。
```

商业里，价格战常常是囚徒困境。

如果所有企业都保持价格纪律，大家都有利润。但单个企业总有诱惑降价抢份额。一家公司降，其他公司怕丢市场，也跟着降。最后大家都降到接近成本线，消费者短期受益，行业利润被打掉。

航空业、大宗商品、同质化消费品、低转换成本服务，都容易陷入这种结构。

这对投资者特别关键。

一家企业再努力，如果所在行业天然鼓励参与者互相伤害，它的长期回报也会受限。坏博弈会吞掉好管理。

## 四、重复博弈：为什么长期关系能产生合作

如果所有互动都是一次性的，背叛常常很诱人。

旅游区的一次性消费、陌生人之间没有追责机制的交易、只做一单的合作，都容易出现短视行为。因为对方知道你不会再来，声誉成本很低。

但现实中，很多博弈是重复的。

同事会继续共事，供应商会继续供货，客户会继续购买，朋友会继续见面，同行会长期相遇。

一旦博弈有未来，合作就不再只是道德选择，而是理性选择。

今天骗一次，可能赚到一点小利；但你失去的是未来多次合作的机会。今天守信用，可能短期不占便宜；但你积累的是长期信任、推荐、低摩擦交易和更好的合作对象。

重复博弈里，一个很强的策略是：

```text
先合作；
对背叛有反应；
对方恢复合作后，也愿意恢复合作；
规则清楚，让别人知道如何与你相处。
```

它不是软弱，也不是报复心重。它的关键是“善意但不任人利用”。

这和芒格式商业哲学很接近：长期诚信、行为透明、珍惜声誉，但不和不可信的人继续玩。

所以，判断一个关系时要问：

```text
这是一次性博弈，还是重复博弈？
对方是否在乎未来？
我是否在乎未来？
有没有机制让背叛付出代价？
```

没有未来的局面，要多加防护。有长期未来的局面，则值得投资信任和声誉。

## 五、零和、正和、负和：先判断游戏性质

很多冲突来自把游戏性质看错。

零和博弈是：你多得一分，我就少得一分。比如一场固定奖金的比赛，一个人赢，另一个人输。

正和博弈是：合作或创新能让总蛋糕变大。比如企业和优秀供应商共同改善流程，成本下降、质量提高，双方都能受益。

负和博弈是：参与者互相消耗，总蛋糕变小。价格战、军备竞赛、恶性内斗、报复循环，常常会变成负和。

很多人把商业本能地看成零和：我赢，就是你输。

但真正优秀的商业模式，常常创造正和关系。客户得到更好产品，企业得到利润，员工得到成长，供应商得到稳定需求，社会得到更高效率。

这也是为什么高质量企业不只是“打败竞争对手”。它们往往建立了一个让多方都愿意持续参与的系统。

博弈论会提醒你：

```text
别急着赢一局，先判断这局是不是值得赢。
```

如果赢法是负和的，短期胜利可能只是长期消耗的开始。

## 六、最好的策略，有时是换一个游戏

很多人学博弈论，会把注意力放在“如何在给定游戏里找到最优策略”。

这当然重要。但更高一层的问题是：

```text
我为什么要玩这个游戏？
有没有更好的游戏可以选？
```

芒格式思维很重视这一点。

如果一个行业天然价格战严重、产品同质、参与者很多、竞争者不理性、资本不断涌入、没有退出纪律，那么你就算很聪明，也只是在一个烂游戏里努力。

更好的做法不是证明自己能打赢价格战，而是避开这种结构。

选择有护城河的企业，本质上是在选择更好的博弈。品牌、转换成本、网络效应、规模优势、专利、渠道控制，都能改变博弈结构，让企业不必每天陷入同质化搏杀。

选择长期合作对象，本质上也是在选择更好的博弈。和重视声誉的人合作，和短期套利的人合作，收益矩阵完全不同。

选择职业平台也一样。一个组织鼓励抢功、甩锅、短期指标和内部斗争，你在里面再努力，也可能被迫玩负和游戏。一个组织鼓励长期积累、透明反馈、合作和信任，你的努力更容易复利。

最高级的博弈思维，不是每局都赢，而是：

```text
多进入正和游戏；
少进入负和游戏；
避开对手不理性的游戏；
主动改变游戏规则。
```

## 七、承诺、信号和威慑

在博弈中，你做什么很重要；别人相信你会做什么，同样重要。

承诺，就是让别人相信你会采取某种行动。

比如一家企业长期坚持“不打折”，一开始可能损失部分销量，但久而久之，客户知道等不到大促，渠道也不会把库存押在折扣上，品牌价格体系更稳定。

再比如一家公司公开承诺“任何质量问题无条件退款”。这不仅是服务政策，也是信号：它向客户表明自己对产品质量有信心。

威慑也是承诺的一种。

如果对手知道你不会回应攻击，他就更有动机攻击你。如果对手知道你会迅速、清楚、有限度地回应，他就会重新计算背叛的收益。

但承诺必须可信。

空口承诺没有用。真正可信的承诺，通常需要付出成本、留下记录、改变激励或限制自己的后路。

比如押金、合同、公开声明、长期声誉、不可撤销投资、制度化规则，都是让承诺更可信的方式。

博弈论里有一个很实用的问题：

```text
我释放的信号，对方会相信吗？
如果不相信，我如何让它变得可信？
```

## 八、警惕不理性的对手

经典博弈论常常假设参与者理性。

现实里，这个假设很危险。

有些竞争者不在乎利润，只在乎市场份额。有些人被面子、愤怒、复仇心驱动。有些公司拿着补贴或融资，可以长期以非经济方式竞争。有些管理者为了短期指标，会牺牲长期价值。

如果你假设对手会理性止损，而对方实际上愿意两败俱伤，你的策略就会失效。

这也是芒格式判断里很重要的一点：不要和不理性的人竞争。

不是因为你怕他们，而是因为他们会破坏收益矩阵。

一个理性对手会计算成本和收益；一个不理性对手可能会为了让你痛苦而让自己也痛苦。前者可以博弈，后者要尽量避开。

所以，在进入一个局面前要问：

- 对手在乎利润吗？
- 对手在乎声誉吗？
- 对手是否有退出纪律？
- 对手是否被补贴、情绪或政治目标驱动？
- 对手有没有能力长期承受亏损？

如果答案让你不舒服，最好的策略可能不是“更聪明地竞争”，而是不参与。

## 九、博弈论在投资中的用法

投资分析里，博弈论最重要的应用，是判断行业结构。

你要问：

```text
这个行业的均衡是什么？
```

有些行业的均衡是高利润。参与者少，产品有差异，客户转换成本高，价格战不容易发生，需求稳定，进入壁垒高。

有些行业的均衡是低利润。参与者多，产品同质，固定成本高，边际成本低，客户只看价格，产能一过剩就互相降价。

一家企业身处什么博弈，比它短期财报好不好更重要。

投资时，可以从几个角度看：

- 参与者数量：越分散，越容易竞争激烈。
- 产品差异化：越同质，越容易价格战。
- 成本结构：固定成本高、边际成本低的行业，容易用低价填产能。
- 进入壁垒：新玩家容易进来，就很难长期保持高回报。
- 竞争者理性程度：如果对手不在乎回报，行业利润会被压低。
- 重复互动：少数长期玩家更容易形成稳定预期。

这也是为什么护城河重要。

护城河不是一个漂亮词，它改变了博弈。它让企业从“谁更便宜”的竞争中脱离出来，让客户不只按价格选择，让对手即使想进攻也成本很高。

好的投资，不只是买好公司，也是买好博弈。

## 十、博弈论在个人生活中的用法

个人生活里，博弈论最有用的地方，不是让你算计别人，而是帮你识别互动结构。

合作前，问对方是否处在重复博弈中。

如果一个人未来还要和你长期合作，还在乎圈子声誉，还会被共同熟人观察，他背叛的成本就更高。反过来，如果对方是一次性交易、没有共同关系、没有评价机制，就需要合同、押金、第三方担保或更小的试错成本。

谈判中，别只想自己底线。

你要想对方的替代选择、压力、激励和可接受结果。你的报价不是孤立数字，它会改变对方对你的判断，也会改变后续互动方式。

团队协作中，关注激励是否把人推向合作。

如果制度只奖励个人短期指标，却要求大家无私协作，那就是在制造囚徒困境。不要只批评人“没有团队精神”，先看收益矩阵是不是鼓励各自为战。

关系中，不要把所有互动都博弈化。

这是边界。亲密关系、友谊、家庭不该被还原成策略游戏。博弈论能帮你识别结构，但如果你用它解释一切，你会失去信任本身。

更好的用法是：在涉及利益、承诺、合作和风险的地方看清结构；在值得信任的长期关系中，主动创造正和。

## 十一、常见误区

第一个误区：以为均衡就是最佳。

均衡只是没人愿意单方面改变，不代表这个结果好。价格战、内卷、军备竞赛、互不信任，都可能是稳定的坏均衡。

第二个误区：把所有博弈都看成零和。

很多场景可以通过合作、创新、规则设计变成正和。把所有人都当敌人，会让你错过长期合作带来的复利。

第三个误区：低估结构，高估道德劝说。

如果收益矩阵鼓励背叛，只靠呼吁合作通常没用。真正要改的是激励、重复次数、透明度、惩罚机制和退出成本。

第四个误区：假设对手完全理性。

现实中的人会受心理偏差、身份、面子、恐惧、嫉妒、激励错配影响。博弈论要和心理学一起用，不能孤立使用。

第五个误区：过度策略化。

不是每次互动都需要“算”。如果一个人把所有关系都当博弈，他会变得短视、冷硬，也更难获得真正的信任。

## 十二、和其他思维模型的关系

博弈论基础和激励机制关系最紧。玩家的策略，通常由收益矩阵和激励结构决定。

它和囚徒困境相连。囚徒困境是博弈论中最经典的坏均衡：个体理性导致集体低效。

它和决策树理论相连。动态博弈可以看成多方版本的决策树，每个节点都要考虑对方反应。

它和不对称性与凸性相连。好的博弈常常让你拥有下行有限、上行开放的位置；坏博弈则可能让你承担负和消耗。

它和护城河相连。护城河本质上是在改变博弈结构，让竞争者难以复制、攻击或逼你进入价格战。

它和承诺装置相连。可信承诺能改变对手预期，从而改变均衡。

它和二阶效应相连。你的行动会改变对方行动，对方行动又会反过来改变你的结果。

它和能力圈相连。你看不懂玩家、激励和规则的博弈，不应该轻易参与。

它也和逆向思维相连。不要只问如何赢，还要问：什么博弈会让我无论多努力都难赢？然后避开。

## 十三、使用检查清单

分析一个博弈时，先识别玩家：

- 谁在局里？
- 谁看似不在局里，但会影响结果？
- 每个玩家真正想要什么？
- 他们的约束是什么？

再看策略：

- 每个玩家有哪些可选行动？
- 我的行动会让对方最可能如何回应？
- 对方的回应又会迫使我做什么？
- 有没有人拥有改变规则的能力？

再看收益：

- 每种策略组合下，谁得益，谁受损？
- 这是零和、正和，还是负和？
- 当前均衡对我有利还是不利？
- 有没有更好的均衡，但单靠我无法到达？

再看时间：

- 这是一次性博弈还是重复博弈？
- 声誉和未来合作是否重要？
- 背叛能否被发现和惩罚？
- 合作有没有回归机制？

最后看选择：

- 我是否必须参与这个博弈？
- 有没有更好的游戏可选？
- 我能否改变收益矩阵，让合作变得理性？
- 我能否通过护城河、承诺、差异化或长期关系改变博弈结构？
- 对手是否理性？如果不理性，我是否应该退出？

## 十四、一句话总结

博弈论基础让你从“我该怎么做”升级为“在这个互动结构里，各方会如何反应”。

它最重要的提醒是：

```text
不要只优化自己的动作；
要理解别人的激励、预期和反应。
```

更进一步，不要只问怎么赢这一局。还要问这是不是一个好游戏：它会导向正和，还是负和？它的均衡对你有利，还是注定把你拖进消耗？它允许长期合作，还是诱导短期背叛？

真正成熟的博弈思维，不是把人都当成对手，而是知道什么时候合作，什么时候威慑，什么时候退出，以及什么时候干脆换一张更好的棋盘。
