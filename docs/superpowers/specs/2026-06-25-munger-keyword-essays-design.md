# 设计文档:芒格关键词深度长文

**日期**:2026-06-25
**状态**:已批准,待进入实施计划

## 1. 目标

把从语料库中提取的芒格高频关键词,每一个单独写成一篇深度长文。第一批按"一类一篇"产出 **8 篇旗舰文章**,覆盖全部 8 个主题分类。每篇必须大量引用原文,且写作风格符合芒格本人的习惯。

## 2. 语料来源

项目根目录下两个目录,共 83 篇、约 124 万字:

- `shareholders/` — 34 篇(蓝筹印花致股东信、西科金融股东会讲话、每日期刊股东会讲话)
- `speech/` — 49 篇(各类演讲、访谈、语录)

所有引用**只能**从这 83 篇中逐字摘取,不得杜撰、不得张冠李戴。

## 3. 关键决策(已确认)

| 维度 | 决定 |
|---|---|
| 叙述视角 | 第三人称·主题解读体(编者解读 + 大量引用并标注出处) |
| 篇幅深度 | 深度长文,每篇 ~3500 字+ |
| 引用密度 | 每篇 ≥12 处引用,横跨 ≥4 个不同来源/年份 |
| 第一批范围 | 一类一篇,共 8 篇 |
| 输出位置 | 新目录 `articles/`,文件名 `关键词-标题.md` |

## 4. 文章模板骨架(每篇 8 个小节)

```
【题记】     一句芒格最锋利的原话 + 出处,blockquote,为全文定调

① 一个钩子   ~200字  用悖论/反差/现实场景把读者拉进来,抛出关键词

② 他怎么定义 ~400字  芒格自己的定义(引 1-2 处原文)+ 概念的思想来源
                     (他从富兰克林/达尔文/谁那里学来)

③ 跨年代的回响 ~700字 时间线证明这是他"常说"的:不同年份、不同场合反复强调
                     (引 3-4 处,每条标年份)

④ 反过来想   ~500字  ★招牌:从反面定义——不具备/违反它会怎样,
                     引"避免愚蠢"式原话 + 一个反面案例

⑤ 跨学科透镜 ~600字  ★招牌:用心理学/数学/生物学/物理学模型解释"为什么成立",
                     引他用某学科模型论证的原文

⑥ 落到实处   ~500字  一个真实案例(喜诗/好市多/房地美/所罗门…),引相关原文,
                     展示概念如何变成真金白银

⑦ 边界与误读 ~250字  这个概念最容易被误用的地方;芒格给的限定条件

⑧ 给今天的你 ~300字  不灌鸡汤,落到可操作的判断/行为;结尾再引一句呼应题记

【出处索引】 列出本文全部引用的来源篇目,便于考据
```

**结构理由**:④逆向 + ⑤跨学科是芒格思维的两根支柱,每篇必有、单独成节。③跨年代回响是"关键词=常说"的直接证据,用时间线把同一思想在 20 年间的不同表述并排,最有说服力。

## 5. 写作 voice 清单——"符合芒格的习惯"(9 条)

写解读文字时(非引用部分)对照:

1. **逆向开路** — 每篇必有"反过来想"小节
2. **格栅思维** — 用跨学科模型解释,而非喊口号
3. **俗语类比** — 多用他的比喻("手里拿锤子的人""踢屁股比赛中的独腿人""老鼠药");尽量引他的原话比喻,不自造
4. **毒舌简洁** — 句子短、判断狠、不绕弯、不堆形容词
5. **案例驱动** — 抽象概念必配真实公司/事件
6. **道德底色** — 落点常在品格、理性、避免愚蠢
7. **引经据典** — 点出他援引的思想源头(富兰克林、达尔文、孔子、凯恩斯)
8. **谦逊自嘲** — 保留他承认错误、自我调侃的口吻
9. **大白话** — 不用学术黑话(数据发现:他自己就刻意避开"锚定""损失厌恶"等术语)

## 6. 引用规范(硬约束)

- 所有引用**逐字 verbatim**,用 blockquote;原文加粗关键句保留加粗
- 每条引用紧跟出处:`——《篇名》年份` 或 `——场合 年份`
- 每篇 **≥12 处引用,横跨 ≥4 个不同来源/年份**
- 只从 83 篇语料中取;写作时用 `grep` 定位原文 → 回源文件逐字核对
- 视觉上:编者的话 = 正文,芒格的话 = blockquote,泾渭分明

## 7. 质量红线

- 不杜撰原文、不张冠李戴(每条引用都回源文件核对)
- 不写成鸡汤或语录堆砌——必须有论证骨架
- 解读与引用视觉分明
- 每篇满足 ≥12 处引用、≥4 个来源/年份的下限

## 8. 输出与命名

- 8 篇 markdown,放在新目录 `articles/`
- 文件名:`关键词-标题.md`(如 `能力圈-知道自己不知道什么.md`)
- 每篇带 frontmatter:


## 10. 写作流程(每篇)

1. 用 `grep` 在 83 篇语料中搜索该关键词及其同义表述,汇总候选原文段落
2. 按"跨年代/跨来源"筛出 ≥12 处、覆盖 ≥4 个来源的引用,逐字核对
3. 按 §4 模板骨架填充,解读文字对照 §5 voice 清单
4. 收尾生成出处索引,核对每条引用的篇名与年份
5. 自检:引用数、来源数、是否有逆向节与跨学科节、是否有杜撰

## 11. 非目标(YAGNI)

- 不在本批次搭建网站前端/页面渲染(仅产出 markdown 源文)
- 不一次性覆盖全部 ~80 个关键词(先验证 8 篇模板)
- 不做英文版/翻译
