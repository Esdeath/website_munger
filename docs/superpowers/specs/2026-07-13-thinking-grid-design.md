# 思维格栅栏目设计

**日期：** 2026-07-13
**状态：** 已确认，等待实现计划评审

## 目标

在左侧导航增加一级栏目“思维格栅”。访问该入口时，页面展示源文件 `思维格栅.md` 的十二层模型导航；其中每个模型入口都能跳转到本站对应的独立模型文章页。

## 内容边界与所有权

- 来源是 `/Users/ruimin/Desktop/code/learn-from-book/EPUB/mental-models/models/`。
- 本站将复制一份索引和全部模型 Markdown 到项目根目录的 `thinking-grids/`。
- 这是一次性快照：不添加同步脚本、符号链接、构建时外部路径读取或更新检测。
- `thinking-grids/` 内的内容随本仓库提交和部署，之后由本站独立维护。
- 索引中通向写作说明、分类原则和待办清单的非模型本地链接会显示为文字，不生成失效的站内链接；锚点和外部链接保持可用。

## 信息架构

```
左侧一级入口：思维格栅
        |
        +-- /thinking-grids/                 思维格栅.md 的索引页
                |
                +-- /thinking-grids/<slug>/  单篇模型页
```

- 一级入口与现有“不可为清单”同级，而不是“解读”下的可折叠分类。
- 索引页完整保留“思维格栅.md”的标题、导语、十二层导航、层级说明、模型表格和使用顺序。
- 模型表格中的 178 个相对 Markdown 链接改为本站模型页链接。
- 单篇模型页复用现有阅读页的纸张式正文、目录和响应式布局；页面信息显示“思维格栅”，不伪造芒格原文引用数或来源数。

## 模块与数据流

1. `src/lib/thinking-grid.ts` 读取 `thinking-grids/`，解析索引和模型 Markdown，产出带标题、slug、摘要、正文和目录的模型记录。
2. `src/lib/navigation.ts` 导出“思维格栅”一级导航项，并根据当前路径设置激活状态。
3. `src/pages/thinking-grids/index.astro` 渲染索引正文。
4. `src/pages/thinking-grids/[slug].astro` 通过静态路径为每个模型生成独立页面。
5. Markdown 渲染层增加仅供思维格栅使用的相对链接解析：存在于模型快照中的 `.md` 目标变成 `/thinking-grids/<slug>/`；锚点与外部 URL 原样保留；其他本地文档链接解除为纯文字。

## 错误处理

- 构建时若 `thinking-grids/思维格栅.md` 缺失、空目录或索引链接指向不存在的模型文件，加载器抛出带文件名的错误，阻止生成带坏链接的站点。
- 模型文件没有 YAML 头也可正常读取：首个一级标题作为标题，正文第一段生成摘要。

## 验证

- 新增单元测试，先证明一级导航、模型加载和相对链接转换在功能缺失时失败，再完成实现。
- 全量检查执行 `npm run check`。
- 构建后检查 `dist/thinking-grids/index.html`：左侧入口存在、十二层索引被渲染，且代表性模型链接指向本站独立页面；检查对应模型 HTML 已生成。

## 非目标

- 不同步外部项目后续变更。
- 不把模型混入现有“解读”主题、文章排序或原文追溯系统。
- 不改动现有文章、原文、主题页或视觉主题。
