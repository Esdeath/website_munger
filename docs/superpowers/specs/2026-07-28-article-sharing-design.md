# 原文与解读文章复制分享设计

## 目标

在“原文”和“解读”详情页提供统一的分享按钮。点击后将当前文章复制到剪贴板，同时写入富文本 HTML 和纯文本 Markdown，使 Word、微信公众号、Notion 等富文本目标保留结构，普通文本目标获得可读的 Markdown。

## 范围

- 覆盖 `/sources/[slug]/` 原文详情页和 `/articles/[slug]/` 解读详情页。
- 不覆盖列表页、侧栏信息、思维格栅、不可为清单和独立嵌入式《探索智慧》阅读器。
- 按钮位于文章标题信息下方，作为文章级操作，不随正文滚动悬浮。

## 复制内容

两种剪贴板格式表达同一份内容：

1. 顶部署名：网站名称“查理·芒格知识库”和当前文章的绝对链接。
2. 正文：当前文章标题与完整正文，保留标题层级、段落、列表、引用、强调和正文链接。
3. 底部署名：再次附上网站名称和当前文章的绝对链接。

富文本使用页面已渲染并清洗过的文章 HTML。纯文本使用内容文件中的原始 Markdown；原文详情页继续去除正文内与页面标题重复的一级标题。首尾信息由共享逻辑生成，链接采用站点 canonical URL。

## 组件与数据流

新增一个共享文章分享组件，由两个详情页传入文章标题、正文 Markdown、渲染后的 HTML 和 canonical URL。组件渲染带复制图标的“分享”按钮，并调用独立的纯函数生成 HTML 与 Markdown 剪贴板内容。

浏览器支持 `ClipboardItem` 时，一次写入 `text/html` 与 `text/plain`。不支持富剪贴板但支持 `navigator.clipboard.writeText` 时，降级为复制 Markdown。复制成功后按钮短暂显示“已复制”；失败后显示“复制失败，请重试”，并保留按钮供再次操作。状态提示通过可访问的 live region 宣告。

## 样式与交互

按钮沿用现有阅读页的克制配色和紧凑尺寸，使用分享图标加文字，不引入浮层或系统分享面板。按钮具有清晰的悬停、键盘焦点和禁用状态；复制进行中避免重复触发。移动端保持稳定尺寸，不挤压标题或遮挡正文。

## 测试

- 纯函数测试：验证 HTML 与 Markdown 都包含顶部署名、文章标题、完整正文和底部署名，且使用当前文章绝对链接。
- 页面接入测试：验证原文和解读详情页都使用共享组件，并传入各自正确的正文。
- 降级逻辑测试或静态契约测试：验证优先写入 `text/html` 与 `text/plain`，并提供 `writeText` 降级。
- 运行 `npm run check` 作为完整验收。

## 验收标准

- 两类详情页均能一键复制完整文章。
- 粘贴到富文本编辑器可保留文章结构和链接；粘贴到纯文本编辑器得到结构清晰的 Markdown。
- 复制内容的开头和结尾都包含“查理·芒格知识库”以及当前文章链接。
- 侧栏目录、文章信息和相关内容不会进入复制结果。
- 成功、失败和兼容降级均有明确且可访问的反馈。
