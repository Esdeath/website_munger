# 思维模型讲义合并设计

**日期：** 2026-07-13
**状态：** 已确认，等待实施计划评审

## 目标

将“思维方法”与“思维模型讲义”合并为唯一的“思维模型讲义”栏目，消除三组重复文章，同时保留非重复内容、案例与来源证据。

## 合并结果

现有内容为 15 篇讲义主线与 9 篇思维方法文章。合并后保留 21 篇文章：15 篇主线讲义、6 篇补充课；下线“思维方法”主题。

### 合并并移除的文章

| 移除文章 | 目标讲义 | 合并规则 |
|---|---|---|
| `多元思维模型-把知识挂上格栅.md` | `思维模型讲义01-为什么不能只拿一把锤子.md` | 以讲义的课程开场为主，吸收原文中的定义、可口可乐案例、铁锤综合症反例、边界与来源。 |
| `概率赔率期望值-把赌注押在错价上.md` | `思维模型讲义02-数学不是公式而是判断力.md` | 保留讲义的复利与数学框架，吸收费马—帕斯卡、赔率与错价、止赎潮/油田/重仓案例、边界与来源。 |
| `Lollapalooza叠加效应-二加二不止等于四.md` | `思维模型讲义15-合奏效应多个模型同时指向同一个结论.md` | 保留讲义的收束作用，吸收叠加效应的正式定义、跨年代材料、成功/失败案例、边界与来源。 |

合并遵循“内容覆盖而非拼接”原则：逐段比较后，仅保留能提供新定义、机制、案例、反例、边界或来源的内容。目标讲义的 `出处索引` 合并两篇原文的去重来源；被吸收的概念在正文相应位置明确说明。

## 信息架构与链接

- `src/content/site.ts` 仅保留“思维模型讲义”主题定义；删除“思维方法”主题定义。
- 所有保留文章的 frontmatter `category` 统一为“思维模型讲义”，侧栏、全部文章页、主题页与相关文章关系据此自动归并。
- 三篇被移除文章的既有 `/articles/<旧-slug>/` 地址生成静态跳转到对应讲义页面，避免外部链接和已索引 URL 失效。
- 补充课保留当前 slug 与标题；只修改分类与顺序字段。

## 内容审计与验证

1. 在实现前建立逐篇合并核对表，列出被移除文章的独有定义、案例、边界和来源，以及它们写入目标讲义的位置。
2. 删除源文章前，确认每个核对项已出现在目标讲义正文或 `出处索引`，且不是仅靠一句泛泛的提及。
3. 添加回归测试，断言主题定义中不存在“思维方法”、保留的 21 篇文章全部归入“思维模型讲义”、主线与补充课按 `order` 排列。
4. 验证三条旧 URL 的静态跳转目标，构建后的“思维模型讲义”主题页包含 21 篇文章，并且侧栏没有“思维方法”。
5. 执行 `npm run check` 与 scoped `git diff --check`。

## 非目标

- 不改动与这两个栏目无关的文章、原文资料或“思维格栅”模型快照。
- 不把六篇补充课硬拆并塞入 01–15 的正文。
- 不保留内容重复的旧页面作为两份独立正文。
