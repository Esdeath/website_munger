# 文章风格

本文件只记录 `articles/` 文章的写作风格和质量标准。文章结构见 [`article-template.md`](article-template.md)。

## 语气

- 第三人称解读体:编者负责解释,blockquote 负责呈现原话。
- 判断要短、准、具体,少用空泛形容词。
- 不把芒格没说过的话伪装成芒格口吻。
- 不用学术黑话替代清楚表达。

## 结构习惯

- 每篇必须有“反过来想”或等价小节。
- 每篇必须有跨学科解释。
- 抽象概念要配公司、人物、事件或市场案例。
- 结尾要落到今天读者能使用的判断动作。

## 论述密度

脚本 PASS 只是底线。文章还要有:

- 清楚的读者问题。
- 足够的解释段落,不只堆引文。
- 误读和边界。
- 至少一个真实案例或反例。
- 和既有长文接近的论述厚度。

## 禁忌

- 不手打引用。
- 不把提问者、编者导言、第三方评论当成芒格的话。
- 不为了顺畅改写原文引用。
- 不用低覆盖关键词硬凑文章。
- 不把同一组引文换个标题重复写。
