# 01 建立原始语料库

本阶段只负责把外部资料变成可追溯的本地 Markdown 语料。

## 放置规则

- 致股东信、股东会、年会问答放入 `shareholders/`。
- 演讲、访谈、书面陈述、专题资料放入 `speech/`。
- 文件名优先使用 `年份 + 资料名`,例如 `2023年 每日期刊股东会讲话.md`。
- 不确定年份时保留原题名,但在 `state/corpus-manifest.md` 标为 `未标明`。

## 入库时必须记录

在 [`../state/corpus-manifest.md`](../state/corpus-manifest.md) 增加一行:

| 字段 | 要求 |
|---|---|
| 本地文件 | 相对路径 |
| 年份 | 资料发生或发表年份 |
| 书名/资料名 | 原始资料标题,不是文章标题 |
| 类型 | 股东信/股东会/演讲/访谈/书面陈述/资料 |
| 来源链接 | 原始链接;没有就写 `未记录` |
| 清洗状态 | 未清洗/已清洗/需复核 |

## 入库边界

- 允许录入翻译稿,但必须保留来源链接或来源说明。
- 不把二次解读文章当作原始语料,除非明确标为“资料”。
- 不在入库阶段提炼观点或改写语义。

## 中文摘要资料

经明确要求收录的中文摘要可放入对应资料目录，但不是可逐字引用的原文。

- frontmatter 必须设置 `source_kind: summary` 和 `quote_count: 0`；文件名、标题以“中文摘要”结尾。
- 正文开头注明“中文摘要，非全文译文，不作为芒格逐字引文使用”，保留原题、日期、作者／发言人／记录者和来源链接。
- 清单类型填“资料（中文摘要）”；已核对摘要可记为“已清洗”，这不表示原文已全文收录。
- 关键词提取、文章写作和引用核验不得把摘要改写当作芒格原话；引用必须返回完整原始资料核验。
- 引用检查器排除摘要正文及其标题；网页仍在对应资料模块显示摘要身份。
