# 03 从语料提取关键词

本阶段只负责把原始资料里的反复表达变成候选关键词。

## 关键词必须来自语料

不要先凭兴趣造题,再回头找材料。候选关键词应来自:

- 高频概念:能力圈、护城河、机会成本、激励机制。
- 固定对象:人物、公司、学科、市场现象。
- 反复表达:比喻、警句、反面提醒。
- 读者问题:能帮助读者做判断的主题。

## 推荐搜索

```bash
rg -n "重要|愚蠢|避免|喜欢|讨厌|模型|心理|错误|教训|机会|风险|长期|资本|声誉" shareholders speech
```

对候选词做二次搜索:

```bash
rg -n -C 3 "关键词|同义词|英文名|相关案例|相关比喻" shareholders speech
```

## 进入注册表的门槛

写入 [`../state/keyword-registry.md`](../state/keyword-registry.md) 前,至少确认:

- 有原始表达,不是概括后硬造的词。
- 有代表来源 `file:line`。
- 预计能支撑 12 处引用、4 个不同来源。
- 能回答一个读者问题。
- 和已完成文章不重复角度。

## 最小记录格式

```text
关键词 / 分类 / 状态 / 代表来源 file:line / 读者需求 / 备注
```
