> 本文件记录第 13 批 3 篇文章生成全过程**每一步的 token 消耗与耗时**,供成本审计与流程优化复盘。
> 流程见 [`docs/playbooks/corpus-to-articles-pipeline.md`](../playbooks/corpus-to-articles-pipeline.md)。
