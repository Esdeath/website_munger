# 芒格知识库网站设计方案

## 目标

基于当前仓库中的 `articles/`、`shareholders/`、`speech/` 三类内容，设计一个以主题地图为入口的芒格知识库网站。网站优先服务想系统学习芒格思想的普通读者，同时为投资研究者保留清晰的原文追溯路径。

本方案只定义网站的信息架构、页面结构、内容关系和视觉方向，不包含前端实现代码。

## 定位

这个网站不是语录站，也不是单纯的资料归档。它的核心阅读路径是：

1. 从一个思想主题进入。
2. 阅读经过整理和解释的专题文章。
3. 在需要时追溯到具体演讲、访谈、股东会或致股东信原文。

内容分为三层：

| 层级 | 目录 | 作用 |
|---|---|---|
| 解释层 | `articles/` | 主阅读内容，承担主题解释、概念连接和读者引导 |
| 年度语境层 | `shareholders/` | 股东会、致股东信、年度问答，用于还原业务和时间语境 |
| 原文语境层 | `speech/` | 演讲、访谈、声明、长篇对话，用于承载思想原文 |

## 设计原则

### 主题优先

首页不按文件夹或年份暴露内容，而是用主题地图组织芒格思想。普通读者先看到的是“芒格在反复讲什么”，不是“仓库里有哪些文件”。

### 原文可追溯

所有解释文章都应保留来源线索。读者读完一个概念后，可以继续查看它来自哪些演讲、访谈或股东会讨论。

### 阅读和研究分层

普通读者需要清晰路径和低进入门槛；研究者需要年份、来源、关键词、引用关系和原文入口。两者不放在同一层级里抢注意力。

### 以现有内容为边界

第一版网站只消费当前仓库已有的 Markdown 内容，不要求重写文章、不要求补全外部数据库，也不把站点设计依赖到尚不存在的复杂标签体系。

## 信息架构

首页采用“主题地图优先”的结构，主栏目建议为六组。

### 投资原则

用于组织芒格关于投资判断、资本配置和长期复利的核心思想。

代表文章：

- 能力圈：知道自己不知道什么
- 护城河：宽且不断变宽的护城河
- 长期持有：坐等伟大公司复利增长
- 复利：让时间替你工作
- 内在价值：价格背后的真实重量
- 机会成本：用最好的选项做标尺
- 资本配置：把现金交给最会用它的人

### 思维方法

用于组织芒格的判断框架和跨学科方法。

代表文章：

- 多元思维模型：把知识挂上格栅
- 跨学科 / 普世智慧：把各学科的大思想综合起来
- 逆向思维：反过来想总是反过来想
- 检查清单：像飞行员一样起飞前逐项核对
- 概率·赔率·期望值：把赌注押在错价上
- 客观与理性：把追求理性当作一种道德义务

### 人性偏误

用于组织芒格关于心理学、误判和群体行为的内容。

代表文章：

- 激励机制：永远别低估它的力量
- 社会认同：别人都这么做的危险
- 过度自信：高估自己的人最危险
- 嫉妒：唯一没有乐趣的罪
- 承诺一致性倾向：别被旧想法锁死
- Lollapalooza 叠加效应：二加二不止等于四

### 品格处世

用于组织芒格关于个人修养、职业伦理和长期可信度的内容。

代表文章：

- 诚信与声誉：最值钱的资产
- 可靠：让自己配得上信任
- 勤奋努力：把眼前的事做好
- 好奇心：永不熄火的学习机器
- 延迟满足：把眼前冲动换成长期胜利
- 谦逊：知道自己几斤几两
- 纪律自律：在别人失去理智时保持清醒

### 商业案例

用于组织公司案例和商业模式分析。公司不作为百科条目处理，而作为芒格思想的案例载体处理。

代表文章：

- 可口可乐：心理学护城河范本
- 比亚迪：押注一个把事情做成的人
- GEICO：回到优秀老本行
- 蓝筹印花：衰落业务里的浮存金
- 西科金融：偶然产生的小公司
- 每日期刊：从报纸到法院软件的风险投资

### 人物与学科

用于组织芒格经常引用的人物和基础学科模型。

代表文章：

- 本杰明·富兰克林：芒格的终身偶像
- 本·格雷厄姆：价值投资之父与一堂未竟的课
- 李光耀：芒格的另一尊半身像

- 凯恩斯：一个改变了主意的聪明人

- 会计学：商业的语言，也是最容易撒的谎

## 页面设计

### 首页

首页的任务是让读者迅速理解网站如何使用，并提供稳定的第一阅读路径。

建议结构：

1. 顶部标题区：一句话说明这是“以主题地图组织的查理·芒格知识库”。
2. 主题地图：六个主栏目，每个栏目显示 4 到 6 个代表关键词。
3. 推荐阅读路径：为新读者提供一条从“能力圈 / 多元思维模型 / 避免愚蠢 / 激励机制”开始的入门路径。
4. 深度专题入口：展示引用数较高、跨来源较多的文章。
5. 原文资料入口：分别进入股东会与演讲访谈资料库。
6. 数据说明：标明当前已有 70 篇解释文章、1281 处引用，以及原文来自股东会、致股东信、演讲和访谈。

首页不放大段说明文字，不把全部文章列表塞进首屏。

### 主题页

主题页负责把同类文章组织成可扫读的列表。

每个文章卡片建议包含：

- 标题
- 关键词
- 一句话摘要
- 引用数
- 主要来源数量
- 相关主题标签

主题页还应保留一个“研究入口”，允许读者查看这个主题下最常被引用的原文来源。

### 文章页

文章页以 `articles/` 中的长文为核心，保持沉浸式阅读体验。

建议增加以下结构：

1. 文章头部：标题、关键词、所属主题、引用数、主要来源。
2. 正文目录：由 Markdown 二级标题生成。
3. 正文内容：保留现有文章结构和引文格式。
4. 来源追溯：列出文章引用过的演讲、访谈、股东会或致股东信。
5. 相关主题：显示同主题或强相关关键词文章。
6. 原文入口：跳转到对应 `shareholders/` 或 `speech/` 原文页。

文章页的设计重点是“边读边能回到证据”，而不是把来源信息藏在末尾。

### 原文页

原文页用于 `shareholders/` 和 `speech/` 内容。

建议结构：

1. 原文标题。
2. 年份和类型：例如“2023 年 / 每日期刊股东会讲话”。
3. 原文正文。
4. 相关关键词：由引用关系或文件内容匹配生成。
5. 被哪些解释文章引用。
6. 同年份或相邻年份资料入口。

原文页不需要重写内容，只需要增加可导航的上下文。

### 索引页

索引页服务研究者，允许按多个维度扫读资料。

建议至少包含：

- 全部文章索引
- 全部原文索引
- 按主题索引
- 按年份索引
- 按来源类型索引：股东会、致股东信、演讲、访谈、声明

搜索和复杂筛选可以作为实现阶段的增强项，不是方案第一版的硬依赖。

## 内容关系

### 文章到原文

`articles/` 文件头部已有 `sources` 字段和 `quote_count` 字段。网站应优先使用这些字段建立文章到来源的关系。

当 `sources` 名称与原文文件名无法精确匹配时，第一版可以先展示来源名称，不强制生成准确链接；后续再建立来源名称与文件路径的映射表。

### 原文到文章

原文页需要展示“被哪些解释文章引用”。第一版可以从文章 front matter 的 `sources` 反向推导，不要求全文级引用定位。

### 文章到文章

相关文章优先使用同 `category` 文章，其次使用人工维护的主栏目分组。第一版不要求语义相似度算法。

## 视觉方向

视觉气质是“研究型阅读室”：克制、清晰、有书面感，适合长文阅读和资料追溯。

不采用财经媒体式首页，不采用语录卡片堆叠，也不做泛黄复古报纸风。整体应更像一个长期维护的思想索引系统。

建议方向：

- 排版：正文优先，长文阅读宽度控制在舒适范围内。
- 导航：稳定左侧或顶部导航，文章页提供目录。
- 引文：引文要明显区别于编者正文，但不要过度装饰。
- 主题标签：用于导航，不作为视觉噪音。
- 色彩：以中性背景和高可读文字为主，辅以少量沉稳强调色。
- 信息密度：专题页和索引页可以较密，文章页保持阅读节奏。

## 第一版范围

第一版应完成：

- 主题地图式首页方案。
- 六个主主题栏目。
- 文章页结构。
- 原文页结构。
- 基础索引页结构。
- 从文章 front matter 读取 `title`、`keyword`、`category`、`quote_count`、`sources`。
- 原文资料按目录和文件名生成基础索引。

第一版不要求：

- 全文搜索。
- 高亮定位到每一条原文引用。
- 自动语义推荐。
- 用户账号、收藏、笔记。
- 外部资料自动抓取。
- 重写现有文章或原文。

## 后续增强

在第一版稳定后，可以逐步增加：

- 全站搜索。
- 来源名称到文件路径的映射表。
- 原文中的引用定位。
- 关键词关系图。
- 年份时间线。
- 主题阅读路径，例如“新读者 10 篇入门”和“投资研究 12 篇进阶”。
- 自动检查断链和元数据缺失。

## 验收标准

设计落地后，一个读者应能完成以下动作：

1. 从首页理解网站不是资料堆放，而是按芒格思想主题组织。
2. 在一分钟内找到一个想读的主题。
3. 从主题页进入解释文章。
4. 在文章页看到引用数和来源。
5. 从解释文章跳到对应原文资料。
6. 从原文页回到引用它的解释文章。
7. 研究者可以通过索引页按主题、年份和来源类型浏览内容。

## 实现前置判断

当前仓库还没有前端工程骨架。若进入实现阶段，建议优先选择能直接读取 Markdown 内容并生成静态页面的方案，例如 Astro 或 11ty。实现阶段需要另写实施计划，明确框架选择、内容解析、路由生成、样式系统和校验脚本。
